    How DiabRetino works

    In one line: this tool grades a retinal (fundus) photograph into one of the five ICDR diabetic-retinopathy severity stages, shows the exact retinal regions that drove the decision, and issues a printable clinical report.

    The pipeline

    1. Preprocess — circular crop + Ben Graham local colour subtraction to bring out microaneurysms, exudates and haemorrhages.
    2. Dual backbone — an SE-ResNet18 attention CNN reads local lesion texture; a compact Vision Transformer reads global vascular context. A learned gate fuses both.
    3. 5-class head — outputs ICDR stages 0–4 with a probability distribution.
    4. Explainability — Grad-CAM heat-maps the regions the network actually used.
    5. Clinical report — ICDR criteria, findings, urgency and laser/anti-VEGF referral flags.

    Sourcing more test images

    • APTOS 2019 — kaggle.com/competitions/aptos2019-blindness-detection (the dataset used for training)
    • EyePACS — eyepacs.org/resources/data-downloads (DR + DME)
    • MESSIDOR-2 / ODIR — large public NPDR collections for the 5-class ICDR coding

    ⚠️ Research / educational screening tool — it supports, and does not replace, an ophthalmologist.
